# SkillSpark Hub

A new website concept: a practical digital-skills learning hub for students.

Includes semantic HTML, SEO metadata, canonical URL, Open Graph, Twitter cards, JSON-LD, robots.txt, sitemap.xml, llms.txt, responsive design, accessibility-friendly navigation and lightweight JavaScript.

For GitHub Pages: upload these files to a repository, then Settings → Pages → Deploy from branch → main → root.

Replace the example URL, email and social profiles with your real details before publishing.
